# 검증 범위

## 실행 검증 (최종 해시 ROM, 헤드리스 snes9x libretro)
- 콜드 부팅 → 타이틀(「사이보그」 로고, 「시작」·「설정」).
- 설정 화면 본창과 난이도·사운드 하위 창(나머지 하위 창은 정적 렌더로 확인).
- 오프닝 프롤로그 자막, 미션 1 타이틀 카드, 브리핑 대사, 사이보그 프로필 대사.
- 팀 편성(능력치 표시, 확인 선택지 예/아니), 출격 화면 「리더: 009」.
- 1스테이지 플레이와 일시정지 「일시정지」.
- 결과·랭킹·컨티뉴 화면.
- 검증용 에뮬레이터는 모두 종료했습니다.

## 정적 검증
- 공개 도구로 재빌드한 결과가 릴리즈 ROM과 바이트 단위로 같음.
- xdelta를 원본에 적용한 결과가 릴리즈 ROM과 같음. 체크섬 유효.
- 빌드 시 모든 대사가 창 폭·줄 수 안에 들어가는지 검사.
- ROM의 영문 문자열 전수 검색: 화면에 나오는 것은 `PAUSE` 하나(번역함).

## 미검증
- 전편 실제 플레이, 미션 2 이후 대사의 실제 화면 표시(줄 넘침 가능성).
- 엔딩·스태프 롤의 실제 화면.
- 다른 에뮬레이터(bsnes 등)와 실기(실제 슈퍼 패미컴·플래시 카트).
