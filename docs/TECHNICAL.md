# 기술 설명

## ROM 구성
- 1MB LoROM → 2MB 확장, 체크섬 재계산.
- 그래픽·맵 자원은 `$8D:DE33`의 3바이트 포인터 표(번호 0~91)로 관리되며 LZSS(2바이트 크기 + 4바이트 헤더)로 압축되어 있습니다. 로더는 `$19:F4A3`(A=번호, X=VRAM 주소).
- 바꾼 자원은 압축하지 않은 리터럴 LZSS 스트림으로 `$B8:8000`부터 새로 적고 포인터 표만 고칩니다(`extras.lz_literal`·`store`·`set_asset`).

## 대사
- 원래 대사는 가나 1바이트 코드열입니다. 번역문은 D 묶음(브리핑·프로필·편성)을 `$A0:8000`, E 묶음(미션 중 통신)을 `$A1:D000`에 두고 원래 포인터를 고쳤습니다.
- 한글은 `$BF:8000` 훅 코드가 출력할 때마다 글리프를 그려 넣는 동적 글꼴입니다. 자원 #02(대사·ASCII 글꼴, 타일 코드 = ASCII)의 $60~$BF 96칸을 링 버퍼로 씁니다. 글리프는 갈무리7 8×8, 본체 색 15·그림자 색 12.
- 글꼴은 게임 중 WRAM에 캐시되므로, 원본 ROM의 세이브 스테이트를 패치 ROM에 불러오면 글자가 깨집니다.

## 그림 글자
- 타이틀(#55 OBJ 16×16): START/OPTION 자리를 「시작」「설정」으로, 로고 아래 「사이보그」를 나눔스퀘어 네오 Heavy 기울임체로.
- 설정(#3 본창 맵, `$8D:A000` 하위 창 17개 14×7 워드, `$19:A090` 난이도 표): #02 글꼴에 8×8 한글 조각을 넣고 맵 워드를 바꿈.
- 팀 편성 능력치: `$19:91C8~922F`의 LDA 즉시값으로 쓰이는 라벨을 #02의 쓰지 않는 기호 칸에 그린 한글로.
- 미션 카드(#5 글자판, #24~28 맵): 부제는 서울한강체 EB 16×16, 「미션」「최종」은 원본 그라데이션 색 배열로. 미션 번호를 찍는 코드의 VRAM 주소(`$19:E426` 등)를 옮김. 같은 #5 판의 LEADER 글자를 「리더」로.
- 브리핑(#18 128×16 스프라이트 띠 8개): 미션·최종 미션·지역명 5개·START를 갈무리9로.
- 결과(#16)·랭킹(#14/#15)·컨티뉴(#10)·예/아니(#35): 원본 16×16 그라데이션 글자 칸과 금속 질감 색표를 재현해 다시 그림.
- 일시정지: OBJ 문자열 `X0 PAUSE`(ROM 파일 오프셋 0xB189)는 스프라이트 글꼴(파일 오프셋 0x903E0 + ASCII×32)에서 글자를 가져옵니다. Z 다음의 빈 칸($5B~$5E)에 「일」「시」「정」「지」를 그리고 문자열을 바꿨습니다.

## 검증 도구
- `tools/emu.py`: snes9x libretro 코어를 ctypes로 불러 화면 없이 실행·입력·캡처·세이브 스테이트를 다룹니다.
- `tools/fresh.py`(부팅 후 타이틀 스테이트), `play.py`(입력 순서 재생·캡처), `vview.py`·`findt.py`·`ashow.py`(VRAM·자원 조사).
